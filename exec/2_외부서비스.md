# 외부 서비스 정보

프로젝트에서 사용하는 외부 서비스의 가입, 설정, 연동에 필요한 정보만 정리한다. 실제 API Key, Secret, Password, Access Token 값은 문서에 직접 기록하지 않고 GitLab CI/CD Variables, Kubernetes Secret, 운영 서버 환경변수에서 관리한다.

## 1. AWS

- 사용 목적: EKS 백엔드 배포, 프론트엔드 정적 배포, 도메인 연결, HTTPS 인증서, 로드밸런싱, 로그 수집
- 사용 위치: Infra, EKS, FE 배포, 백엔드 운영 환경
- 설정 위치: AWS Console
- 사용하는 서비스:
  - EKS
  - EC2 Managed Node Group
  - Application Load Balancer
  - Route 53
  - CloudFront
  - S3
  - ACM
  - CloudWatch
  - IAM
  - CloudFormation
- 필요한 정보:
  - AWS Account ID
  - AWS Access Key ID
  - AWS Secret Access Key
  - AWS Region
  - Route 53 Hosted Zone
  - ACM Certificate
  - CloudFront Distribution ID
  - S3 Bucket Name
  - EKS Cluster Name
- 현재 Region:
  - ap-northeast-2
- 현재 EKS Cluster:
  - rebloom
- 현재 Frontend 도메인:
  - https://rebloom.cloud
- 현재 Backend API 도메인:
  - https://api.rebloom.cloud
- CI/CD 변수:
  - AWS_ACCESS_KEY_ID
  - AWS_SECRET_ACCESS_KEY
  - AWS_DEFAULT_REGION
  - CLOUDFRONT_DISTRIBUTION_ID
  - DEPLOY_S3_BUCKET
