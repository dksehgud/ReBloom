# Re:Bloom

> 아이, 보호자, 상담사 계정과 관계 연결, AIoT 기기 등록은 미리 완료해 두었습니다.

## 0. 사전 준비: 기기 연동 및 관계 연결 확인

![부모-상담사 연결.gif](docs/%EC%82%B0%EC%B6%9C%EB%AC%BC/%EB%B6%80%EB%AA%A8-%EC%83%81%EB%8B%B4%EC%82%AC%20%EC%97%B0%EA%B2%B0.gif)
![회원가입.gif](docs/%EC%82%B0%EC%B6%9C%EB%AC%BC/mobile/%ED%9A%8C%EC%9B%90%EA%B0%80%EC%9E%85.gif)
![기기연동.gif](docs/%EC%82%B0%EC%B6%9C%EB%AC%BC/mobile/%EA%B8%B0%EA%B8%B0%EC%97%B0%EB%8F%99.gif)

### 목표

본 시연에 들어가기 전, 아이와 보호자, 상담사, AIoT 기기가 이미 연결되어 있음을 캡처 기반으로 짧게 보여준다.

### 구성 방식

이 단계는 실시간 조작 시연이 아니라, 사전에 준비된 화면 캡처를 짧게 이어 붙여 구성한다.

### 캡처 순서

| 순서 | 화면/장치             | 캡처 내용            | 확인 포인트                  |
|----|-------------------|------------------|-------------------------|
| 1  | 아이 앱 또는 가입 정보     | 아이 계정이 생성된 상태    | 시연에 사용할 아이 계정이 준비되어 있다. |
| 2  | 보호자 앱             | 보호자 계정이 생성된 상태   | 보호자 계정으로 로그인할 수 있다.     |
| 3  | 보호자 앱             | 연결된 아이 정보 화면     | 보호자와 아이가 연결되어 있다.       |
| 4  | 보호자 앱             | 상담사 연결 상태 화면     | 보호자와 상담사가 연결되어 있다.      |
| 5  | 상담사 웹             | 상담 아동 목록 또는 대시보드 | 상담사가 해당 아이를 조회할 수 있다.   |
| 6  | 보호자 앱 또는 기기 설정 화면 | AIoT 기기 등록/연동 상태 | 아이에게 블루밍 기기가 연결되어 있다.   |

### 촬영 포인트

- 각 캡처는 2~3초 정도만 노출한다.
- 개인정보가 보이는 경우 이름, 이메일, 주소는 시연용 계정 정보만 사용한다.
- 관계 연결 화면에서는 “연결됨”, “상담사 연결”, “기기 등록 완료”처럼 상태가 드러나는 부분을 중심으로 보여준다.
- 이 단계는 길게 설명하지 않고, 본 시연의 전제 조건을 빠르게 확인하는 용도로 사용한다.

### 강조 메시지

> 본 시연은 아이, 보호자, 상담사, AIoT 기기가 모두 연결된 상태에서 시작합니다. 이를 바탕으로 아이의 기록과 분석 결과가 보호자와 상담사에게 어떻게 전달되는지 보여드리겠습니다.

![아이 일기작성.gif](docs/%EC%82%B0%EC%B6%9C%EB%AC%BC/mobile/%EC%95%84%EC%9D%B4%20%EC%9D%BC%EA%B8%B0%EC%9E%91%EC%84%B1.gif)
![상담사_우울_지표_확인.gif](docs/%EC%82%B0%EC%B6%9C%EB%AC%BC/%EC%83%81%EB%8B%B4%EC%82%AC_%EC%9A%B0%EC%9A%B8_%EC%A7%80%ED%91%9C_%ED%99%95%EC%9D%B8.gif)

### 목표

아이가 작성한 일기와 감정 기록이 분석되어 보호자 앱과 상담사 웹에서 확인되는 흐름을 보여준다.

### 진행 순서

| 순서 | 시연자 | 화면/장치 | 행동                       | 기대 결과                        |
|----|-----|-------|--------------------------|------------------------------|
| 1  | 아이  | 아이 앱  | 아이 계정으로 로그인한다.           | 아이 일기 화면으로 이동한다.             |
| 2  | 아이  | 아이 앱  | 오늘의 감정을 선택한다.            | 감정 선택 상태가 반영된다.              |
| 3  | 아이  | 아이 앱  | 짧은 일기를 작성하고 저장한다.        | 일기가 저장되고 분석 요청이 발생한다.        |
| 4  | 보호자 | 보호자 앱 | 아이 일기/감정 분석 기록을 확인한다.    | 보호자가 아이의 감정 기록과 분석 내용을 확인한다. |
| 5  | 상담사 | 상담사 웹 | 해당 아이를 선택하고 분석 기록을 확인한다. | 상담사가 아이의 일기 기반 분석 정보를 확인한다.  |

### 목표

아이의 이상 신호가 감지되었을 때 보호자에게 알림이 전달되고, 보호자가 즉시 대응하기 어려운 경우 AIoT 스마트 스피커 블루밍이 아이와 대화를 시작한 뒤 상담사가 대화 분석을 확인하는 흐름을 보여준다.

### 진행 순서

| 순서 | 시연자 | 화면/장치    | 행동                         | 기대 결과                     |
|----|-----|----------|----------------------------|---------------------------|
| 1  | 시스템 | 보호자 앱    | 이상치 알림 팝업을 표시한다.           | 보호자가 아이의 이상 신호를 즉시 확인한다.  |
| 2  | 보호자 | 보호자 앱    | 보호자가 직접 대응 불가 또는 거절을 선택한다. | AIoT 대화 시작 요청이 발생한다.      |
| 3  | 블루밍 | AIoT 기기  | 블루밍이 아이에게 대화를 시작한다.        | 아이가 부담 없이 현재 상태를 말할 수 있다. |
| 4  | 아이  | AIoT 기기  | 아이가 블루밍과 대화한다.             | 대화 내용이 분석 대상으로 수집된다.      |
| 5  | 시스템 | AI/분석 서버 | 대화 내용을 분석한다.               | 대화 감정, 키워드, 위험 신호가 분석된다.  |
| 6  | 상담사 | 상담사 웹    | 상담사 대시보드에서 대화 분석을 확인한다.    | 상담사가 대화 기반 분석 정보를 확인한다.   |
